## 项目经历

### BS · 岗位技能差距分析与学习规划系统

**从“这个岗位需要什么”，走到“我接下来应该学什么”。**

面向准备就业的学生，把岗位技能要求、个人自评和学习安排连接起来。针对岗位信息分散、差距难解释、学习目标缺少先后顺序的问题，提供方向选择、技能自评、差距报告与学习计划。

- **技术栈：** Vue 3、TypeScript、Pinia、ECharts、FastAPI、MySQL、Spark / PySpark、FP-Growth。
- **实现要点：** 用词典与别名规则整理岗位技能，按固定方向和资料范围汇总需求；结合需求权重对照自评与目标等级，并保留报告版本。学习规划展开人工维护的前置关系，再按可投入时间安排逐级任务。
- **项目思考：** 把结果解释到具体技能和输入依据。自评覆盖度用于理解固定范围内的差距，不等同于能力认证或录用概率。

[查看项目介绍与操作演示 →](https://chenc55.github.io/projects/bs/)

### 青衿 · HireFlow

**让简历筛选有依据，让协作交接有记录。**

围绕岗位整理简历材料、辅助评估与人工处理流程，解决材料归属不清、评分理由难核对、HR 与招聘负责人交接不连贯的问题。

- **技术栈：** React、TypeScript、TanStack Query、FastAPI、PostgreSQL、PyMuPDF、DeepSeek API、Docker Compose、Nginx。
- **实现要点：** PDF 解析保留文本块与页码，独立 Worker 执行解析和评分任务；模型提供逐项评价和引文，服务端回查来源并计算结果。报告绑定岗位与材料版本，由 HR 核对回传，招聘负责人另行记录决定。
- **项目思考：** 将模型建议、可核对的原文依据和人的最终判断分别呈现，保留历史结果，便于回看处理过程。

[查看项目介绍与操作演示 →](https://chenc55.github.io/projects/hireflow/)

### 微语 · WXtool

**从聊天概览进入原文，给日常沟通一次有上下文的回看。**

基于 **WechatVibe 二次开发**的 Windows 聊天回顾与分析工具。通过会话概览、消息统计、关键词搜索和原文定位，帮助理解已加载聊天的规模与节奏，并提供可选的分析入口。

- **技术栈：** Electron、HTML / CSS / JavaScript、Python、Node.js、TypeScript、ONNX Runtime、SQLite。
- **实现要点：** Electron 承载界面，Python 组织账号与消息读取；前端对已加载消息去重并计算时段、数量和发言比例。分析层按配置调用本地模型或远程 API，结果按账号和分析来源保存在 SQLite 中。
- **项目思考：** 先呈现可以核对的统计与原文，再展示模型分析。远程 API 会接收相关上下文，因此不能把整个工具描述为全程离线。

[查看项目介绍与操作演示 →](https://chenc55.github.io/projects/wxtool/)

## 项目中的关注点

- **从使用流程拆解需求**：先梳理用户要完成什么，再组织页面入口、操作步骤和反馈。
- **让结果有依据**：为评分、统计和历史记录保留输入范围与来源，便于理解和回查。
- **把功能连接起来**：关注界面、接口、后台任务与数据存储之间的衔接。
- **照顾实际操作体验**：保留清晰的下一步、状态反馈、手机布局与键盘操作路径。
